# Spaceflight News
**Android приложение для просмотра новостей о космических полетах** с возможностью добавления в избранное.

## Возможности
- Список новостей о космосе
- Добавление/удаление из избранного
- Детальная страница статьи
- Локальное сохранение избранного (Room DB)
- Обновление списка

## Стек технологий
- Kotlin + MVVM
- Room Database
- Retrofit + Gson
- Glide (загрузка изображений)
- ViewBinding
- Koin (Dependency Injection)

## Установка
1. Клонируйте репозиторий: https://github.com/voidnllptr/homework-3/tree/dev
2. Откройте проект в **Android Studio**
3. Запустите на устройстве или эмуляторе (**API 24+**)
